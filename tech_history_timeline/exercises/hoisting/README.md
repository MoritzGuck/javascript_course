# Mission: The Hoisting Incident

## Objective

The Chrono-Vault's fragment recovery system crashed during a quantum surge. The diagnostic log shows two near-identical scripts — one worked, one threw `TypeError: recoverFragment is not a function`.

Your mission: figure out **which one crashed and why**, then repair the broken one.

## Your Tasks

1. Read `fragment_script.js` and predict the output of **both** blocks.
2. Run it (`node fragment_script.js`) and compare your prediction with reality.
3. Fix the **broken** block so it runs without errors.
4. In your own words (in the file as a comment, or out loud to Chrono), explain *why* one worked and one didn't.

## Checklist

- [ ] Predicted the output of both blocks
- [ ] Ran the script and confirmed the crash
- [ ] Repaired the broken block
- [ ] Explained the difference to Chrono
